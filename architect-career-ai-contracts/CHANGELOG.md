# Changelog

All notable contract changes are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-07

### Added

- OpenAPI 3.1 modular REST contracts for Knowledge, Learning, Career, Portfolio, Chat, and Health
- Shared schemas for Problem Details (RFC 9457), pagination, security, errors, and metadata
- AsyncAPI 3.0 modular event contracts for Knowledge, Learning, Career, Portfolio, and AI processing lifecycle
- Generator profiles for Java (OpenFeign), Python (Pydantic), and TypeScript (Axios)
- AsyncAPI payload JSON Schema export pipeline
- GitHub Actions validation and generation workflow
- Contract governance documentation set
